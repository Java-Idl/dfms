Security Challenge Verification Lab
All 7 Defenses Active

Trigger real-time attack simulations to verify DFMS security controls and failsafes against the API.

Defense 1
GPS / Location Spoofing
Injects coordinate jump with impossible kinematic velocity (>60 m/s) to trigger the plausibility filter and return-to-home failsafe.
Defense 2
Unauthorized Mission Modification
Simulates in-flight waypoint tampering without a valid cryptographic HMAC signature — rejected by flight controller.
Defense 3
Command & Shell Injection
Injects shell metacharacters in drone identifier to verify strict regex allowlist rejection (HTTP 400).
Defense 4
Operator Impersonation (IDOR)
Fleet Alpha operator attempts to cancel a Fleet Beta drone command — rejected by fleet-scoped authorization (HTTP 403).
Defense 5
Drone Hijacking / Nonce Replay
Replays a previously captured valid command packet. Drone-side replay cache detects duplicate nonce and drops packet.
Defense 6
Telemetry Confidentiality
Inspects mTLS session parameters: TLS 1.3 encryption, AES-256-GCM cipher, and mutual certificate verification.
Defense 7
Denial of Service / Rate Limiting
Simulates API request burst flood to test rate limiting (HTTP 429) while emergency CANCEL commands retain priority.
